# 🎬 YouTube Video Chatbot

A RAG-based chatbot that answers questions about any YouTube video using its transcript.

## Tech Stack
- Python
- LangChain
- Groq LLM (llama-3.1-8b-instant)
- FAISS Vector Store
- HuggingFace Embeddings
- Streamlit
- YouTube Transcript API

## How to Run Locally
1. Clone the repo
2. Create `.env` file and add `GROQ_API_KEY=your_key`
3. Install dependencies: `pip install -r requirements.txt`
4. Run: `streamlit run youtube-chatbot.py`
